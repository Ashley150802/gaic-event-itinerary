Architecture

System architecture, data model, layer boundaries, and design principles that govern every extension.

1. Design Principles

#PrincipleRationale
1One Store contract, many driversAll data access goes through the Store interface. Swapping storage never touches business logic.
2Pure analyticsaggregate.ts has zero I/O — deterministic, trivially testable, identical across runtimes.
3One composition layerservice.ts wires Store + aggregate + live hub. Both Node and Cloudflare call the same functions.
4Framework at the edges onlyHono routing in app.ts. Entry points just construct dependencies and hand them to createApp.
5No native modulesStorage uses Node's built-in node:sqlite. No C/C++ toolchain needed.
6Client-side preferencesTheme, density, color mode live in localStorage. Zero backend writes for UI state.

3. Domain Model

erDiagram
    EVENT ||--o{ SEGMENT : contains
    EVENT ||--o{ SURVEY : has
    SURVEY ||--|{ QUESTION : defines
    SURVEY ||--o{ RESPONSE : collects
    RESPONSE ||--|{ ANSWER : holds
    SEGMENT }o--o| SURVEY : links
    EVENT { string id PK  string slug UK  string title  string status  string theme }
    SURVEY { string id PK  string eventId FK  string title  string status  string joinCode UK }
    QUESTION { string id PK  string surveyId FK  string label  string type  bool required }
    RESPONSE { string id PK  string surveyId FK  string channel  string createdAt }
    ANSWER { string id PK  string responseId FK  string questionId FK  any value }
EntityDescription
EventTop-level container. status: draft | live | archived, a theme, organizer, URL slug.
SegmentItinerary entry. Kinds: keynote, session, workshop, panel, break, networking, survey. Ordered by position.
SurveyA set of questions. status: draft | live | paused | closed, mode: standard | live, a short joinCode.
Questiontype: rating | single | multi | number | text | nps | scale | date. Extensible config.
ResponseA respondent's submission. Holds channel and optional note.
AnswerPer-question value inside a response. string | number | string[].
SurveyResultsComputed analytics: tallies, NPS, sentiment, keywords, daily timeline, monotonic version.

Theme System

Supports dark, light, and system (follows OS preference):

  • CSS variables on :root (dark) and [data-color-mode="light"] (light)
  • 5 accent themes: Aurora, Ember, Forest, Violet, Rose — each with light-mode contrast overrides
  • Persistence: localStorage via surket.settings key
