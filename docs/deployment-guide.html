Deployment Guide

Surket targets three deployment environments. The same code runs on all three because every runtime constructs a Store + live hub and hands them to the shared Hono app.

Prerequisites

  • Node.js ≥ 22.5.0 (24+ recommended)
  • pnpm 9+ (pnpm workspace)
  • No C/C++ toolchain, Python, or Build Tools needed

Option 1 — Local / Self-Hosted (Node.js + SQLite)

git clone https://github.com/LehroSolutions/surket.git
cd surket && corepack enable && pnpm install

# Terminal 1 — API server
pnpm --filter @surket/server dev

# Terminal 2 — SPA
pnpm --filter @surket/web dev

Environment Variables

PORT8787HTTP port
SURKET_DB./surket.dbSQLite file path
ADMIN_TOKENunsetProtects write routes when set

Option 2 — Cloudflare (Workers + D1 + Durable Objects)

Recommended for production: durable storage + true push-based live tally.

  1. cd server && pnpm exec wrangler login
  2. pnpm exec wrangler d1 create surket — copy database_id to wrangler.toml
  3. pnpm exec wrangler d1 migrations apply surket --remote
  4. pnpm --filter @surket/web build
  5. pnpm exec wrangler secret put ADMIN_TOKEN
  6. pnpm run deploy:cf

Cloudflare Bindings

BindingTypePurpose
DBD1 databaseDurable storage via d1Store.ts
LIVE_TALLYDurable ObjectPer-survey live WebSocket fan-out
ASSETSStatic assetsServes the built SPA from web/dist
ADMIN_TOKENSecretGates write routes

Option 3 — Vercel (SPA + Serverless API)

  1. Push the repo to GitHub
  2. Import in Vercel — build settings are encoded in vercel.json
  3. Set ADMIN_TOKEN and SURKET_DB (libSQL/Turso URL) in the Vercel dashboard

Live Tally on Vercel

Serverless functions are short-lived — /api/config reports polling. The SPA polls /results on version changes. For push-based updates, integrate a Cloudflare Durable Object, Upstash, or Ably.

Post-Deployment Checklist

  • Set ADMIN_TOKEN (prevents unauthorized writes)
  • Verify /api/health returns { ok: true }
  • Create a test event via the dashboard
  • Submit a test response via the join flow
  • Verify live tally updates
  • Configure dark/light mode in Settings
