Completed Milestones

v1.0 — Foundation

  • Event + Survey + Question CRUD
  • 8 question types
  • Pure analytics engine (zero I/O)
  • Runtime-agnostic Store interface
  • Node.js local development (node:sqlite)
  • Hono HTTP framework with security stack
  • React 19 + Vite 8 frontend

v1.1 — Live Tally & Deployment

  • WebSocket live tally (Node + Cloudflare)
  • Polling fallback (Vercel)
  • Live presenter big-screen view
  • Cloudflare Workers + Vercel deployment
  • Template gallery

v1.2 — UX & Theming

  • Dark / Light / System color mode
  • 5 accent themes with light-mode contrast
  • Smooth CSS transitions + GSAP animations
  • Responsive mobile layout
  • Public itinerary + QR sharing
  • Comprehensive documentation suite

Prioritization Principles

  1. Attendee experience first — features that make responding easier get priority
  2. Presenter confidence — live tally reliability is non-negotiable
  3. Operator efficiency — reduce clicks to create, manage, and analyze events
  4. Runtime parity — every feature must work on Node, Cloudflare, and Vercel
  5. Zero-config defaults — new features should work out of the box
