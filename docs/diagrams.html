1 System Layers

Surket follows a strict layered architecture. The browser talks to Hono routes, which call the service layer, which composes the Store interface and the pure analytics engine.

Browser

React 19 SPA with Vite 8. Custom router (no react-router). GSAP animations. CSS custom properties for theming.

Service Layer

Single composition point. Wires Store + aggregate + LiveHub. Identical on all runtimes.

Pure Analytics

aggregate.ts has zero I/O. Given survey + answers, returns SurveyResults. Trivially testable.

Store Drivers

sqliteStore.ts for Node, d1Store.ts for Cloudflare. Same portable SQL, no dialect differences.

3 Live Tally Pipeline

Real-time result streaming from respondents to a big-screen presenter view. Transport-agnostic: WebSocket on Node/Cloudflare, polling on Vercel.

sequenceDiagram
    participant R as Respondent
Phone
    participant API as Hono API
    participant Svc as service.ts
    participant DB as Store
    participant Hub as LiveHub / DO
    participant P as Presenter
Screen

    R->>API: POST /surveys/:id/responses
    API->>Svc: submitResponse(store, hub, id, body)
    Svc->>DB: createResponse()
    Svc->>DB: getAnswerRows()
    Svc->>Svc: aggregate(results)
    Svc->>Hub: publish(surveyTopic, results)
    Hub-->>P: WebSocket push
{ type: "results", version }
    API-->>R: 201 { results, version }

    Note over P: If WebSocket unavailable,
polls GET /results every 3s
re-renders only on version change

Node.js

In-process LiveHub pub/sub. WebSocket upgrade on /api/live/:topic. Zero external services.

Cloudflare

Per-survey LiveTallyRoom Durable Object. Holds WebSocket connections and broadcasts to all subscribed clients.

Vercel

Client polls GET /api/surveys/:id/results every 3 seconds. The version field prevents flicker — UI only updates when version increases.

Version Counter

SurveyResults.version is a monotonic counter = total response count. Single source of truth for "has anything changed?"

Node.js

Best local dev experience. Hot reload. WebSocket live tally. Persistent SQLite file. Run with pnpm dev.

Cloudflare

Edge deployment. D1 for persistence. Durable Objects for WebSocket. Modern assets binding serves the SPA. Zero cold starts.

Vercel

Serverless functions. Ephemeral SQLite (demo only). Polling-based live tally with 3s interval. Zero-config deploy via vercel.json.

Persistence

localStorage key: surket.settings. Survives reloads, tabs, and browser restarts. Zero backend writes.

System Preference

window.matchMedia("(prefers-color-scheme: light)") with change listener. Auto-switches when OS setting changes.

Transitions

transition: background .35s ease, color .25s ease on body, sidebar, topbar, and cards for smooth mode switches.

Meta Sync

<meta name="theme-color"> updates to match the active mode. Mobile browser chrome matches app background.
