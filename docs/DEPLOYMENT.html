Deployment (Quick Reference)

Surket targets Vercel and Cloudflare out of the box. No native build tools required.

No native build tools. The Node/Vercel runtimes use Node's built-in node:sqlite, not better-sqlite3, so installing and deploying requires no C/C++ compiler, Python, or Build Tools. Needs Node 22.5+.

Option 1 — Vercel (SPA + serverless API)

  1. Push the repo to GitHub and import it in Vercel.
  2. Build settings (already in vercel.json):
    • Build: pnpm install && pnpm --filter @surket/web build
    • Output: web/dist
    • /api/* routed to the serverless function
  3. Set environment variables: ADMIN_TOKEN, SURKET_DB (durable libSQL/Turso URL)

Live tally on Vercel

Serverless functions can't hold WebSocket connections. /api/config reports polling. The SPA polls /results on version changes.

Option 2 — Cloudflare (Workers + D1 + Durable Objects)

Recommended for production: durable storage + true push live tally.

  1. pnpm install then cd server && pnpm exec wrangler login
  2. Create D1: pnpm exec wrangler d1 create surket — copy id to wrangler.toml
  3. Apply migration: pnpm exec wrangler d1 migrations apply surket --remote
  4. Build SPA: pnpm --filter @surket/web build
  5. Set secret: pnpm exec wrangler secret put ADMIN_TOKEN
  6. Deploy: pnpm run deploy:cf
